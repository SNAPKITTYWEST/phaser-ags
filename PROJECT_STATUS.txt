SYSTEM FEATURES
================================================================================

Exception Handling (12 types)
  • Undefined Instruction → process kill
  • SVC Call (syscall) → dispatcher
  • Prefetch Abort (code fault) → page fault
  • Data Abort (load/store fault) → page fault or kill
  • IRQ (external) → PLIC dispatch
  • FIQ (fast) → priority interrupt

Virtual Memory
  • 2-level page tables (L1=4096 entries, L2=256 entries)
  • 4KB pages + 1MB sections
  • Page allocation (buddy allocator)
  • TLB: 32 entries, flushable by VA/ASID/global
  • Page fault handling with recovery
  • mmap/munmap with rollback

Process Management
  • Process: PID, state, address space, fd table, trap frame
  • States: READY, RUNNING, BLOCKED, ZOMBIE
  • fork: clones address space, trap frame, fd table
  • exec: replaces image, jumps to entry point
  • exit: closes fds, frees memory, becomes zombie
  • kill: terminates and frees resources
  • reap: collects zombie children

Scheduling
  • Preemptive round-robin (32 priority levels)
  • Time slice = 10ms (configurable)
  • Context switch: r0-r15, spsr, sp swap
  • Reschedule on timer tick
  • Ready queue management

Device I/O
  • UART0 @ 0x4806A000 (kernel console)
  • UART1 @ 0x4806C000 (user I/O)
  • GPIO0 @ 0x48310000 (32 pins, FPGA ctrl)
  • PLIC @ 0x0C000000 (RISC-V standard)
  • Memory-mapped I/O with proper barriers

Shell
  • Interactive command interpreter
  • 18 built-in commands
  • Process inspection (vmmap, vmtrans, pages)
  • VM operations (vm on/off, vm page)
  • LED/GPIO control
  • Memory debugging (hexdump, memdump)

MEMORY LAYOUT
================================================================================

Physical (OMAP3530):
  0xFFF00000  Reset Vector (256B, ROM)
  0x00000000  SRAM (128KB, Stage1 boot)
  0x30000000  DRAM Boot (256KB, Stage2)
  0x30040000  DRAM Kernel (4MB)
  0x30440000  DRAM User (variable, heap/stacks)
  0x08000000  NOR Flash (256MB)
  0x40000000  NAND Flash (512MB)
  0x48000000  Peripherals (16MB, I/O)

Virtual (per process):
  0x00000000  TEXT (code)
  0x04000000  DATA (initialized)
  0x02000000  BSS (uninitialized)
  0x30000000  USER HEAP (grows up)
  0x30440000  USER STACK (grows down, 64KB)
  0x80000000+ KERNEL SPACE (unmapped in user)
